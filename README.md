# 刷B站 (BiliScroll)

让 Bot 真的去「刷」B 站：看画面、读评论区，看到有意思的主动分享给你。

它不会把热门榜单直接发给你，而是像人一样刷到一个东西、有点反应、顺手跟你说一句，再把视频发过来。

---

## 效果长什么样

你会在 QQ 里收到这样的消息：

```
涨两千叫微涨 跌五十叫暴跌
[视频文件]
```

或者：

```
教室里还有人还能拍完 真当同学不是人啊
[视频文件]
```

先说一句它自己的话，再把视频发过来。点开就能看，带声音。

---

## 工作原理

1. 拉取 B 站首页个性化推荐（用你配置的 Cookie）
2. 按设定时长过滤，随机抽几个候选
3. 每个候选：抓取高赞评论 + 下载视频 + 均匀抽帧
4. 把「标题 + 画面截图 + 高赞评论」一起交给 LLM
5. LLM **先从评论区理解这视频的梗在哪，再用自己的话说出来**
6. 私聊发送：先说感想，再发视频文件

### 关键设计：为什么要有评论区

只给画面时，模型会说出「这两个小人对着捶胸好魔性」这种抽象、老套的话，因为它不知道视频真正的笑点在哪。

高赞评论是**集体反应**，直接揭示了梗的位置。有了它，输出会变成有具体指向、像人说的话。

提示词里还特意允许「说得跟评论一样短」，防止模型为了显得有观点而硬加评价尾巴。

## 依赖

```bash
pip install yt-dlp imageio-ffmpeg
```

约 45MB。`yt-dlp` 下载视频，`imageio-ffmpeg` 抽帧。

---

## 安装

把 `astrbot_plugin_biliscroll` 整个目录放进：

```
AstrBot/data/plugins/astrbot_plugin_biliscroll/
```

重启 AstrBot。

---

## 配置

在 AstrBot WebUI → 插件 → 刷B站 中配置：

| 配置项 | 说明 | 默认 |
|---|---|---|
| `bilibili_cookie` | B站 Cookie，需含 SESSDATA，**必填** | 空 |
| `target_umo` | 分享给谁，格式 `平台名:FriendMessage:QQ号` | 空 |
| `enable` | 启用自动分享 | 关 |
| `daily_min` / `daily_max` | 每天分享几个 | 2 / 3 |
| `max_duration_minutes` | 只挑多长的视频 | 10 |
| `candidates` | 每次给几个候选让它挑 | 3 |
| `frames_per_video` | 每个视频抽几帧 | 6 |
| `quiet_hours_start` / `end` | 免打扰时段 | 1 / 8 |
| `llm_provider_id` | 指定模型，留空用默认 | 空 |

### 怎么拿到 Cookie

1. 浏览器登录 B 站
2. F12 → Application → Cookies → `https://www.bilibili.com`
3. 复制 `SESSDATA` 的值（必需）
4. 也可以把整串 Cookie 粘进去

## 注意事项

### B 站接口是非官方的

本插件调用的是 B 站网页端接口，不是官方开放 API。

- 接口可能随时变动导致失效
- 如果请求量过大，可能触发风控，**影响你账号的正常使用**
- 建议不要设置过高的分享频率

### Cookie 是明文存储的

你的 B 站 Cookie 会以明文保存在：

```
AstrBot/data/config/astrbot_plugin_biliscroll_config.json
```

- 这个文件**不要发给任何人**
- 不要截图贴到公开场合
- Cookie 等于登录凭证，泄露后他人可以操作你的 B 站账号

### 建议配置人格

插件会读取 AstrBot 当前的**人格设定**（persona）参与生成。

如果没配置人格，输出会偏向「AI 助手」的语气，效果会明显变差。建议先给机器人配一个人格，写清楚说话习惯。

### 会消耗 LLM token 和流量

- 每次分享要调用一次带图片的 LLM
- 每个视频约 7MB，一天 2-3 条约 20MB 流量
- 下载和抽帧依赖网络速度

---

## 已知限制

- **只能通过抽帧「看」画面**，不是完整理解视频，对节奏、音乐、快速剪辑的内容理解有限
- **评论过滤较严格**，含特定词汇的评论会被整条丢弃，可能误伤
- **长视频会被跳过**，默认超过 10 分钟的不刷
- **不同视频效果差异较大**，有明确梗的视频效果最好，纯视觉类效果一般
